How metrics are calculated

Current post metrics use a rolling 30-day sample. Date range explores observation history; current channel cards stay current.

Subscribers

Last measured subscriber count. Its observation timestamp is shown separately when a collection could not refresh it.

Typical 24 / 48 / 72-hour views

Average views measured at the selected post age for eligible posts published in the preceding 30 days. Measurements are collected within 60 minutes after each horizon; coverage shows measured / eligible posts. Missed or older measurements remain unavailable and are never reconstructed from lifetime counters.

ER

(Reactions + comments + forwards) ÷ post views × 100%. Counts use the same recent post sample and latest stored observations.

ERR

Average current post views ÷ last measured subscribers × 100%. This is separate from fixed-age views.

Channel statistics plot actual observations only. Post totals retain Daily posts or Cumulative in window. Weekly/monthly channel plots use the latest recorded observation in each bucket. Unknown values remain gaps. ER/ERR comparisons use percentage points (pp).

The 30-day sample and collection tolerance are TGhost conventions; exact TGStat numerical parity is not implied.
