# TGhost README visuals

The logo and three product demos are copied unchanged from
[tghost.app](https://tghost.app/). The demos show a fictional channel and sample
content; they are illustrative previews, not live channel data.

`readme-banner.svg` adapts the website’s headline, dark teal grid and mint accent,
with the original mascot embedded so the banner works without external assets.
